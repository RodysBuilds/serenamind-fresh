# SerenaMind opnieuw publiceren

## Aanbevolen: nieuwe repository

1. Maak op GitHub een nieuwe openbare repository met de naam `serenamind-fresh`.
2. Upload alle losse bestanden uit deze map naar de hoofdmap van de repository.
3. Ga naar Settings > Pages.
4. Kies Source: Deploy from a branch.
5. Kies Branch: main en Folder: /(root).
6. Klik Save.
7. Wacht bij Actions tot de Pages-run groen is.
8. De site staat daarna op de GitHub Pages-link die bij Settings > Pages wordt getoond.

## Belangrijk
- Upload de bestanden zelf, niet de bovenliggende map.
- `index.html` moet direct in de hoofdmap staan.
- Verwijder een oude SerenaMind-beginscherminstallatie voordat je de nieuwe versie toevoegt.
- Accounts blijven alleen op hetzelfde apparaat en in dezelfde browser bestaan.
- Wis geen websitegegevens als je een lokaal account of dagboek wilt behouden.
